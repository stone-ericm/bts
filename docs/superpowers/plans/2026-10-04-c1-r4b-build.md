# C1 rank 4b build plan (implements the FROZEN registration `docs/sota_audit/2026-10-04-prereg-c1-longest-streak-policy.md`)

**Rule:** every task is test-first. Its synthetic tests fail before the code exists. **No outcome-bearing profile values are read before X-31 is published** and the code review signs; schema and dates may be read.

**Code:** `scripts/audit/c1_r4b/`. **Tests:** `tests/scripts/c1_r4b/`.

**Facts the build rests on (read 10/04):**
- **Profiles:** 120 files at `data/hetzner_results/mdp_estpa_run/<box>/simulation_seed<N>/backtest_<season>.parquet` (24 seeds × 2021–2025), about 1,820 rows each.
  - Columns: `date, rank, batter_id, game_pk, p_game_hit, actual_hit, n_pas, est_pas, starter_pas, reliever_pas, source_n_pas, p_hit_vs_reliever, p_game_hit_basis, total_batter_games, starter_matchup_batter_games, dropped_no_starter_matchup`.
- **A0 base:** `data/models/mdp_policy.npz` (sha `66d15471…`): `policy_table` (58, 181, 2, 5) int8, one `boundaries` array (4), `season_length` 180.
- **A0 tail:** `data/models/mdp_tail_policy.npz` (sha `dc5d0c99…`): `policy_table` (58, 58, 29, 2, 1), one bin, `max_days` 28, bound to the base sha.
- **A0 routing in production:** `strategy.py:227–306`; `mdp.lookup_action` caps days at the table horizon.

## Tasks
| # | Module | What it does | Key tests (synthetic, red first) |
|---|---|---|---|
| T1 | `calendars.py` | Builds one outcome-free calendar per season from the public MLB regular-season schedule (one request per season; frozen JSON plus sha): opening date, inclusive final date, exclusive end, and no-opportunity dates (calendar days without a scheduled game). Raw days left = max(0, exclusive_end − date). | calendar arithmetic; the 9/25 → 9/28 gap example (row countdown [2, 1] against calendar [4, 1]); no-opportunity classification; the late phase defined by calendar, not by observed dates |
| T2 | `profiles.py` | Loads the 120 profiles: validates schema, identities, ranks, probabilities and labels; refuses malformed, duplicate or ambiguous rows. Pairs rank 1 with the first lower-ranked candidate in a different game. Classifies each calendar date as available-with-partner, available-partnerless, primary-absent, evidenced no-opportunity or unknown coverage. | pairing rules; duplicate and malformed refusal; date classification against the calendar; counts by season and seed |
| T3 | `fit.py` | Builds the fold classifier (five-bin quintile cutpoints on pooled rank-1 probabilities from the fitting seasons; a value equal to a cutpoint goes to the upper bin) and the phase split (the last 30 calendar days). Estimates availability-conditioned rates (p_hit and p_both on partner-eligible days; p_hit alone on partnerless days) and type frequencies on opportunity dates. Stops on a degenerate bin. | `0 ≤ p_both ≤ p_hit` holds by construction; the 2-date mixed-denominator counterexample is refused; zero-weight cells are kept; a degenerate bin stops |
| T4 | `solvers.py` | A phase-aware whole-season backward induction with a legal availability kernel: the E[best] objective (state s, m, d, saver, q; stop rule; play-first ties) and the reach-57 objective (skip-first ties). Assembles A1 (reach-57 where s + 2d ≥ 57, else the matched E[best] continuation). | **independent tiny-path enumeration oracle** (a brute force over all outcome paths) for both objectives, including m-dependent policies; equality with `solve_mdp` on an all-partners kernel; a partnerless double counted +1; a double crossing 57; saver catch and no reuse; the early/late transition |
| T5 | `replay.py` | The corrected realized-sequence replay: calendar clock, availability, legal demotion, m-state, the 57 cap, the one-use saver at streaks 10–15. Providers for A0 (own boundaries, base/tail routing, horizon caps, trusted-best stop), A1, A2, always-single and legal always-double. Δ thinning: r_bar from the fitting seasons, 200 replicates, seed 20261004, common masks, nested uniforms; Monte Carlo SE per replicate set. Metrics: mean capped max, reach 20/30/40/57, resets, action counts, demotions, decision consequences under both visitation weightings. | a scalar reference replay equals the vectorized one; the s + 2d = 57 boundary; tail routing on both sides; skips consume calendar time; an unknown-coverage date |
| T6 | `parity.py` | Reproduces the July Δ = 0 anchors (`ANCHOR_DIFFGAME`, `ANCHOR_TOL`) with the old semantics through the existing module. A failure stops the run. | wiring only (the anchors need the real profiles: an outcome-bearing step, run after X-31) |
