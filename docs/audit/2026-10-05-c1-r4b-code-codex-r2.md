**Locations:** `scripts/audit/c1_r4b/generator_check.py:89–103`; `tests/scripts/c1_r4b/test_generator_check.py:38–43`.

A read-only one-row synthetic comparison returned `{"differing_cells":{"actual_hit":1},"reproduced":false}`. A mismatch count is a measure of that label, even without a floating-point magnitude or a literal row value. The regression test currently requires this violation and names it “counted but never measured.”

The helper does not directly print row values in the tested paths. Its floating diagnostics also cover every non-label float column, not just the prediction columns claimed by the docstring.
