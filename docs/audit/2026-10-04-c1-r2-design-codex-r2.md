Three clarifications are required for the final frozen text:

1. **Receipt prose must distinguish an actual completed observation from a republished marker or skipped job.** Lines 30–31 and 54 name the correct prerequisites but do not yet state how their consumer can reject these cases. The existing entry command timestamps markers with its initial `now`, and a date-only `confirmed` takes an early return (`src/bts/cli.py:1643–1645,1693–1695,1749–1751`). Reconcile skips unresolved dates, pending answers and answers crossing cutoff, while returning only corrections (`src/bts/picks.py:1128–1141,1186`). Without E1, adding fields around those old values can satisfy the apparent receipt shape without proving the required observation. The existing fetch schedule remains unchanged. Producer schemas/paths and validation belong in the separately reviewed producer diffs, not another rank-2 design round.

2. **A closed relevant writer interval needs an evidence requirement, not a waiting heuristic.** Lines 58 and 67 correctly prohibit a mixed-snapshot verdict, but matching repeated hashes or a quiet process cannot establish that closure. The real scorer writes `streak.json` before the terminal pick save inside its lock (`src/bts/cli.py:2302–2316`); a writer paused between those saves can look stable. E2 requires a production-capable consistent capture, bound to actual bytes and an as-of interval, or an unverifiable result. This implements the existing requirement without granting the watchdog a production lock or repair authority.

3. **Separate synthetic code acceptance from operational commissioning.** Items 1–4 are retained, item 5 and its two installation/activation bullets are present, and §5 has exactly three bullets with no old runtime estimate or budget waiver. E3 removes any interpretation that production must already be installed to obtain the code signature that authorizes putting deployment to Eric. The intent-aware install can coincide with A5 when he plays; installing the watchdog never independently restores recommendation delivery or entry nags.

No additional blocking design defect was found.
