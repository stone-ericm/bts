### 4. BLOCKER — §6.3: ordinary setup assertions can become accepted XFAILs

### 7. SHOULD — §6.3: an empty correction list is not a general state-no-op contract

The design already rejects import errors and unrelated failures (D:98). The edits above make that requirement testable; they do not replace it with “any nonzero exit means reproduced.”
