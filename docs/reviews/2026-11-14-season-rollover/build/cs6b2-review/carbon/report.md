## Notes
1. **`stat()`-to-`open()` TOCTOU window (`src/bts/health/alert.py:101-112, 174-176`):** `_read_health_dm_delivery_status` checks `stat.S_ISREG(path.stat().st_mode)` before `path.read_text()`, and `_persist_health_dm_delivery_status` checks `stat()` before `write_text()`. Replacing a regular file with a directory, missing path, or symlink loop between `stat` and `open` raises `OSError` and recovers cleanly, whereas atomically swapping in a writerless FIFO in that microsecond seam blocks `open()` (`probe_dispatcher_and_parity.py`, `race_stat_then_fifo` hit 0.5s `SIGALRM`, exit 42).
