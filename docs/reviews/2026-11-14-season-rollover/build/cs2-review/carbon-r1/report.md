## The corrupt-file question
- **Contract-level critique (Definitions + Rows 1–3, separate from code defects):** Defining "matches season Y" so that corrupt, non-UTF-8, or non-object `streak.json` (`b"{"`, `b"\xff"`, `b"[]"`, `chmod 000`) returns `(0, True, [])` causes dated scoring to silently overwrite corruption from fresh state.
- **Observed runtime behavior at `3b4196be` (`probe_corrupt_during_scoring` in `differential-probes.log`):**
  - **Hit or miss (`cli.check_results` and `scheduler.run_result_polling` midgame/final):** `_load_streak_season` returns `{}` with **zero log or alert**; `update_streak` atomically overwrites `streak.json` (`streak: 1, saver_available: true, season: Y` on single hit; `0, true` on miss) and saves `daily.result`. `run_result_polling` immediately posts a false `Streak: 1` (or `0`) reply to Bluesky. In `scheduler.run_day` (`L3273 -> L3311`), EOD `health/streak_validation.check` runs *after* polling, sees valid JSON, and emits `[]` (**no alert**); next morning `contest_state.load_decision_streak_state` sees `model_state_error=None`, defeating CS1's corrupt-model-fallback `ContestStateError`. At 02:00, `reconcile_results` repairs the streak **only if** every prior pick in `Y` is readable and terminal; if any earlier pick is unresolved (e.g. `2027-03-10.json` outside the 8-day lookback), `_replay_season_streak` returns `None` and the silent reset (plus lost `[10, 15]` saver forgiveness, resurrected spent saver, and wiped L04 `applied_dates`) becomes **permanent**.
  - **All-void day:** `update_streak` is not called; scorers exit `0` (`Streak unchanged: 0`), save `result="void"`, and leave corrupt bytes on disk (`b"{"` triggers `streak_validation` alert; `b"\xff"`/`b"[]"` raise `UnicodeDecodeError`/`AttributeError`, caught as CRITICAL by `health/runner._safe_run`).
  - **Directory or `DEEP`:** `IsADirectoryError` (at `os.replace`) or `RecursionError` (`B1`) aborts before `save_pick`.
- **Judgement:** Quiet repair during scoring is **not safe**; `d8eb50d0`'s loud failure blocked false Bluesky streak replies, preserved corruption visibility for `streak_validation` and CS1's `contest_state`, and prevented permanent resets when season history has an unresolved gap. **Recommendation:** revise the contract to match CS1's `contest_state._load_model_diagnostics` — missing file and valid JSON dicts with missing/mismatched `season` return `(0, True, [])`, while unreadable/non-UTF-8/non-object `streak.json` raises in readers and `update_streak` (leaving only `reconcile_results`'s full-season replay overwrite to replace a corrupt file).
