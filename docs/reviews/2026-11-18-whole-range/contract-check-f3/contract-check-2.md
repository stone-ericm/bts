## Replacement texts

- **Design 2, input handling.** “In `day_outcome.py`, use a single nonblocking open per optional evidence file. Verify that the open file is regular, then read at most 64 KiB plus one byte before decoding UTF-8 or parsing JSON. Treat a larger file as absent evidence. `read_regular_file_text` as it stands is unbounded. Keep enumeration failures, per-file failures and timestamp conversion failures local to the evidence they affect. Require the dated v3 schema tag explicitly before calling `validate_dated_observation`. Validate the switch with `validate_contract`.”
- **Design 2(a).** “For reason (i), prefer a valid current dated observation for D. If unavailable, choose the valid D archive with the latest offset-aware `recorded_at`. When newest archives tie and disagree on active streak or policy saver availability, omit reason (i). Reason (ii) can still use any validated D dated observation to establish a match. The request log stays outside the evidence.”
- **Design 3, eligibility and (ii).** “Evaluate either reason only for a base `deliberate_skip` with an embedded date equal to D, `scoreable` exactly false, `streak` an exact nonnegative integer and `saver_available` an exact boolean. Reason (ii) requires report-time enter intent, a validated switch for D’s season that is still revoked, a `revoked_at` on D in ET, and no valid current or archived D observation with both policy inputs equal to the skip’s.”
- **Design 3 result and Design 4 text.** “Return problem state `skip_state_review` when a reason applies, using the base exit 1 and DM handling. `detail` opens with ‘The policy recorded a skip for {D} using streak {S} and policy saver availability {A}.’ Use either ‘The installed dated observation for {D} records streak {S2} and policy saver availability {A2}.’ or ‘An archived dated observation for {D} records streak {S2} and policy saver availability {A2}.’ For (ii) use ‘The season switch records a revocation on {D} at {T} ET.’ Close with ‘Check MLB for unsettled entries and verify the current streak, season best and saver.’ Keep the base message prefix, which renders `SKIP STATE REVIEW`. Use that state in the examples and CLAUDE.md.”
- **K2a–d and K5.** “K2a: A valid matching current dated 30 stays clean, including when an archive has a later request timestamp. K2b: After a request is logged but fails to install, keep the report based on the installed state. K2c: Pre-check enable and successful fetch stay clean, also after a same-day prior revoke. K2d: A restore revoke followed by matching dated 30 stays clean while matching evidence is retained. K5: Bad optional files and base-readable skips with unusable evidence fields keep the base result. Test each optional input independently, including the byte limit and ET conversion overflow. Failures of the base readers keep their existing behavior.”
- **Known and not fixed 1–3.** “The decision record establishes neither the order of the evidence nor which reading the skip used. The reporter compares a retained current observation or archive for D and the switch snapshot it reads. Returned inputs, best-only changes, legacy and automatic-only updates are outside the dated comparison. A later write or restore can remove a mismatch or remove a match, exposing older evidence or a revoke. A later revoke can archive D’s observation or overwrite the only D switch timestamp. A matching archive or a re-enabled switch can hide a revocation that did affect D. Reason (ii) uses report-time intent, so an intent cutover can hide a live revoke or flag a research skip. Older/incomplete records and reads concurrent with state writes can also leave evidence incomplete.”
