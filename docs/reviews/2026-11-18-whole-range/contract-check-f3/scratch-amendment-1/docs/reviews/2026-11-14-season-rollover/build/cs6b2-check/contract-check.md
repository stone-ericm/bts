## Reader and dispatcher replacement clauses

- **MUST FIX — Row 1.** Accept `str` input and normalize subclasses through `str.__str__` so overridden hooks cannot run during decoding. Catch `ValueError` (including JSON syntax and conversion-limit errors) and `RecursionError` from decoding. Reject non-object roots and keep the existing schema, exact-bool `scoreable`, date-presence and exact-string action checks. Return the decoded object unchanged and retain Python's duplicate-key semantics. Scope the guarantee to supported inputs and ordinary parsing failures. Resource exhaustion such as `MemoryError`, programmer errors and interrupts are outside it. Pin top-level `NaN` as rejected by shape and embedded `NaN` as preserved legacy behavior. Python also accepts lone surrogates in JSON strings, including escaped surrogates decoded from valid UTF-8. Neither implies the decision input bytes were wrongly decoded.
- **MUST FIX — Row 2.** Open/read once using the pick loader's text decoding behavior on captured bytes. Preserve raw bytes on every parse/decode rejection, including `b""`, and use `raw=None` only when no complete read succeeded. Reserve `absent` for a genuinely missing path. Compatibility wrappers may still expose `None` and `(None, raw)` / `(None, None)`. Check embedded date against the requested date in the authority read.
