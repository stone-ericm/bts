## Replacement contract text

**Definition (live, identity and fresh choice).** A live scheduler or orchestrator uses its existing required-state predicate. Non-dry `bts run` always requires contest state. Classify the observation from the winning snapshot in the loader, using its existing pinned clock and file identity. In-effect dated uses `dated` with padded effective date, active streak, best streak and saver state. Automatic file uses `automatic`, selected other manual uses `legacy_manual`, and absence uses `model`; their dated identity is null. Keep the two default fields as drafted. A fresh choice has both `sel.decision` and `sel.pick_result.daily`. This includes MDP and heuristic singles and doubles. A skip has a decision without a pick. All four existing-pick return sites, grouped as lock, status failure and unavailable candidates, are reuse. At a scheduler send, exempt a same-cycle fresh choice only when the caller supplies that fresh selection for the exact `daily` instance being sent. File reloads and absent selection evidence count as saved.

**Definition (record and match).** Retain the draft's exact six outer keys and four dated keys. Validate decoded objects by exact key sets, exact schema/enums, `type is bool` for booleans and `type is int` for counts. Counts are nonnegative; automatic streak is at most 57, and dated counts satisfy `active <= best <= 57`. The dated date must parse and round-trip as padded `YYYY-MM-DD`. Its active streak equals the outer streak and its saver agrees with the existing policy-saver function. `dated` is null for the three other kinds. Missing, null or malformed records mean absent. Keep the existing whole-file JSON decoder and its limits. A valid record matches only with `required is True` and either equal dated identity on both snapshots or `automatic` on both snapshots. The automatic comparison deliberately admits reading, saver, activation and season changes, and resumes after a dated override lapses. Compare against the completed delivery-read snapshot; there is no transaction with subsequent updates or transport.
