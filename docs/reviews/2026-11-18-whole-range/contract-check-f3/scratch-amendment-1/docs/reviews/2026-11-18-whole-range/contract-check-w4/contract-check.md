# NOT YET

W4 needs a change at the point where it sends, archives, or alerts. A fresh call to the planner before unchanged helpers leaves the stale-state failures inside those helpers. W4 would add those actions on days where `main` takes none. The smallest safe version is a stranded-pick trigger with guarded actions enabled only for W4 and one recoverable missed-pick check for the slate. Keep the existing paths for other days.

## Last inputs before each action

| Action | Last sample and read under W4 v1 | Remaining I/O or missing check |
| --- | --- | --- |
| Sleep to D, A or k | Trigger or pending clock, pick/decision at trigger | Journal, heartbeat, notify and state writes can overrun the target. Recompute remaining time after those writes. A stale pre-helper k clock can sleep twice. |
| Refresh or save its result | Item 3 wake pick/decision and clock, then a pre-refresh clock for excluded games | Intent save and confirmation sync precede refresh. Its cascade, status lookup and provenance writes precede the pick write. Recheck authorization and cutoff at both boundaries. |
| Defer or late/void refusal | Post-sync time and in-memory planner inputs, or chokepoint status and cutoff clock | Archive mkdir/write and source lookup precede unlink. Refusal journal can block first. A knowledgeable status result must survive replanning. |
| Recover, send or lock | Wake snapshot for recovery, fresh cutoff and contest observation for send, current object for private lock | Marker save precedes transport. Private save, success save and commit/lock writes can see a changed file/decision. Recovery can clobber a private commit. Bind confirmation and finalization to the same attempt. |
| Capture or clear skip | Refresh selection plus in-memory skip state | State save and any post-refresh work can intervene. Revalidate authoritative commit/skip before persisting either change or proceeding. |
| Contest, refusal, C2 or missed alert | Refresh error/status/refusal, or A's pick and decision snapshot | Journal, archive, state/dedup reads and receipt work precede transport. For a missed alert, recheck authority/time after preparation and before transport. A refusal alert reports a completed refusal. |

Use the actual cascade end for the `finished` sort key, or a slow action changes the last-two budget ordering. An interrupt before the last save otherwise loses the measurement.
