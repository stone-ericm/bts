## Why it stopped (round-2 blocking findings; obligations for any next attempt)
1. **The test override reaches production gates (Carbon B2(a); lead reproduced by reading `scripts/install-deploy-guard-hetzner.sh:138`).** `TEST_ROOT = os.environ.get("BTS_TEST_DEPLOY_GUARD_DIR") if os.geteuid() else None`: every gate that runs as `bts` (the scheduler's `ExecCondition`, the cron `run` gate, the dashboard's saver check) honours the variable, so a value in `.env`, the user manager's environment or a drop-in points the gate at an empty directory and the scheduler starts during a hold. **Obligation:** the installed tool must have no override path at all (tests run an uninstalled copy with an explicit root argument), and preflight refuses if the variable appears in `.env` or the unit environment.
2. **The crontab inventory is a pattern match, not an inventory (Carbon B1, Codex r2 1).** A backslash inside the command word (`re\concile`), an indirect entry point, a short-circuited heartbeat line (`true || …`), `@reboot`, a second `--deploy-hold=` argument and a gated `echo bts check-results` all pass. **Obligation:** compare the installed BTS lines with the exact lines `cron-setup-hetzner.sh` renders for the configured intent (byte for byte, secrets compared by hash), and refuse every other uncommented line that mentions `bts`, `uv` or the project path.
3. **Unit checks miss namespace and hook settings (Carbon B2(b), Codex r2 3).** `RootDirectory`, `BindPaths`, `BindReadOnlyPaths`, `TemporaryFileSystem`, `PassEnvironment`, `UnsetEnvironment`, `ExecStartPre`, `ExecStartPost`, `ExecStopPost` are not queried. **Obligation:** an allowlist of the effective unit's properties against the template, not a denylist.
4. **The runtime validator is a re-implementation (Carbon B3, Codex r2 4; lead reproduced: `fallback_deadline_min = 20` with the default morning 25 passes the validator and raises in `resolve_fallback_deadline_min`).** Also a `heartbeat_path` under a regular file, overflowing or negative minute settings; and the other way, a working SSH tier with `platform = "linux"` is refused. **Obligation:** the canary must call the scheduler's own parsers (refactor them out of `run_day` as pure functions used by both), not a parallel checker; and it must be run once against the box's real configuration before any guarded deploy (F16).
5. **Race and liveness edges (Codex r2 2, 5, 6).** A hook that timed out on the transaction lock can stop a scheduler a later deploy just started; an ET rollover between the last clock sample and the unlink still commits; the hand release accepts a fresh `stalled` heartbeat from a process an earlier failed stop left alive. **Obligation:** the hook's fallback stop must be serialised with state changes (or removed in favour of the next preflight); the hand release must verify the scheduler inactive with no `MainPID`; the dated-midnight case should refuse activation in a window around ET midnight rather than chase the clock.
