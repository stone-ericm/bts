## Known limits

- R2 sync uploads the current file and rotates two manifest generations. Hashing a FIFO at the active cache path can still block sync.
- A custom picks parent can put health out of reach of the cache-relative status directory. Stderr still reports incidents. A backtest in the live checkout can observe and rewrite the same cache.
- Concurrent writers can overwrite each other's additions. A repair requires stopping the scheduler and letting active feature runs finish before cutover.
- Health DM delivery retains its existing receipt behavior. A failed send needs a later run to present the alert again. The failure banner counts CRITICAL alerts only. Empty transport IDs can count as sent. A restart after a send and before its receipt can repeat the DM.
