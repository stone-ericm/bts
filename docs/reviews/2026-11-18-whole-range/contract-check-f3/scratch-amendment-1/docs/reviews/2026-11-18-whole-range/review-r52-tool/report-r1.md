## Notes

- On the correct grid, pairing new minus old, equal season weights, sample SD and the one-sided t quantile with 7 df match R52 before floating-point effects. The scorecard call `compute_precision_at_k(df, k_values=[1])` is the API spelling of R52's `k=1`. It averages `rank <= 1` hits within dates, then averages dates. Missing rank 1 drops a date, an all-missing top pick cell is unmet, and NaN hits drop from the daily mean. One null hit gave P@1 `149/199` while the loader reported 200 days. A mixed-year file returned 2. Equal-count shifted dates passed silently and unequal counts only warned. [Scorecard](../../src/bts/validate/scorecard.py#L18)
- The runner uses `estimated_pa`. The writer emits `date`, `rank`, `batter_id`, `game_pk`, `p_game_hit`, `actual_hit`, `n_pas` plus estimated-PA diagnostics. Rows are batter-games, so a doubleheader can repeat the batter on one date. `nlargest` keeps first ties before numbering 1 through up to 10, so ties and doubleheader rows yield one rank 1 per nonempty day. Outcomes are max binary PA hits. NaN **scores** can still receive ranks and P@1 uses the outcomes. [Writer](../../src/bts/simulate/backtest_blend.py#L620)
- `--streak` without `--json` printed neither metric. The pooled five-season replay carries streak and saver state over offseasons, so drop `longest_replay_streak` or compute it per season. Label mean max streak as 180-day pooled bootstrap under `combined`, and exact P(57) as the scorecard's binned Markov estimate with an approximate saver and a different double-down trigger. Rank-2 absence reuses rank 1 in Monte Carlo and drops the date from the exact bins. Null hits can abort streak computation and hide an otherwise computed verdict.
