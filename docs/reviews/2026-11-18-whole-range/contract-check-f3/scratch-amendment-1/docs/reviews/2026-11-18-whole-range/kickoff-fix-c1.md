## The defect
The end-of-day health run for processed day D can run after midnight ET (the last game ended after 00:00). `contest_state.check` reads the wall clock, so on a day that ran on a dated observation for D, that observation has expired by the time the check runs: the check falls back to whatever automatic file is on disk and sends a false CRITICAL (and the saver WARN), whose command template is dated D+1, before MLB has settled D's pick. Following it writes a pre-settlement streak for D+1.
